# Caddy web server — content discovery wordlist
#
# Built for Command Bridge. SecLists has Apache, nginx, IIS and Tomcat
# lists; it has no Caddy list, which is why this one is bundled.
#
# What it is for. Caddy's own attack surface is not files on disk the
# way Apache's is — it has no .htaccess, no /server-status, no
# /icons/. What it has is a JSON ADMIN API that can replace the running
# configuration, and which is supposed to be bound to localhost:2019.
# The finding worth hunting is that API reachable through the public
# listener: a reverse-proxy route that forwards everything, a
# `bind 0.0.0.0` on the admin block, or a container where the admin
# port was published. POST /load to a reachable admin API replaces the
# server's whole config, which is remote code execution in practice.
#
# Paths below are from Caddy's own API documentation. Hit any of them
# with a 200 on a public listener and the admin API is exposed.
#
# Lines beginning with # are comments; ffuf, feroxbuster, gobuster and
# dirsearch all skip them.
