# Spring Boot — content discovery

# The finding on a Spring Boot app is almost always an exposed Actuator.
# /actuator/env and /actuator/configprops leak configuration including
# credentials; /actuator/heapdump downloads the live heap (a memory
# disclosure that often yields session tokens and secrets); /actuator/
# mappings and /actuator/beans map the whole app. Older apps expose these
# at the root (/env, /health) rather than under /actuator.
